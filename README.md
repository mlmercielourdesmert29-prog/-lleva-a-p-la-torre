# Lleva a P a la torre 🎯

Minijuego interactivo sobre **vectores en el plano cartesiano**.

Elige las cartas de desplazamiento correctas para mover el punto **P** desde su posición inicial hasta la **Torre Resultante**. Cada carta es un vector (x, y): al usarla, P se desplaza esa cantidad en cada eje.

## ▶️ Jugar

**https://TU-USUARIO.github.io/lleva-a-p-la-torre/**

Funciona en computadora, tableta y celular. No hay que instalar nada.

## Cómo se juega

- Dos equipos compiten: **Kiwi** y **Mandarina**. Toca el nombre del equipo que está jugando.
- Toca una carta para mover a P con ese vector.
- **Deshacer** quita la última carta; **Reiniciar** vuelve a empezar el nivel.
- **Pista** muestra cuánto falta por recorrer (final − inicial).
- **Modo rápido**: 3 niveles. **Modo completo**: 5 niveles.

## Lo que se practica

- Componentes de un vector (x, y)
- Suma de vectores: (a, b) + (c, d) = (a + c, b + d)
- Vector entre dos puntos: final − inicial
